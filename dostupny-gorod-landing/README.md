# Доступный Город — Лендинг

Одностраничный сайт (лендинг) стартапа «Доступный Город» — карта доступности для маломобильных граждан.

Соответствует **Практическому занятию №3 / №4** (Хостинг продающего сайта) и **бренд-борду** проекта.

## ✅ Соответствие требованиям

| Требование | Реализация |
|-----------|-----------|
| Минимум 5 ключевых блоков | ✅ Hero + Проблема + Решение + Как работает + Волонтёрам + CTA + Footer |
| Рабочее целевое действие (CTA) | ✅ Форма заявки с валидацией + ссылка на Telegram |
| Брендовая идентичность | ✅ Цвета #29B6F6 / #78909C / #263238, шрифты Manrope + Inter, логотип и иконка из бренд-борда |
| Адаптивный дизайн | ✅ Mobile-first, breakpoints 980 / 720 px |
| Реальные скриншоты приложения | ✅ Макеты интерфейса (вход, маршрут, волонтёр) |
| Онлайн-доступность | ✅ Готово к деплою (GitHub Pages / Vercel / Netlify) |

## 📦 Структура блоков

1. **Hero** — заголовок, УТП, CTA, статистика + скриншот приложения
2. **Проблема** — 3 карточки с болями целевой аудитории
3. **Решение (УТП)** — галерея реальных скриншотов + 4 пункта уникального предложения
4. **Как работает** — 3 простых шага
5. **Волонтёрам** — социальное доказательство + скриншот кабинета волонтёра
6. **CTA** — форма заявки (имя, email, роль, согласие) с валидацией
7. **Footer** — контакты и навигация

## 🎨 Бренд

- **Основной цвет:** Небесно-голубой `#29B6F6`
- **Дополнительный:** Стальной серый `#78909C`
- **Контрастный:** Тёмный уголь `#263238`
- **Шрифты:** Manrope (заголовки) + Inter (текст)
- **Логотип и иконка:** из бренд-борда

## 🚀 Локальный запуск

Откройте `index.html` в браузере — сборка не требуется.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 🌐 Публикация

Рекомендуемые платформы из задания:

- **GitHub Pages** — просто залить папку в репозиторий
- **Vercel / Netlify** — drag-and-drop или git-интеграция
- **Tilda / Carrd** — можно перенести контент в конструктор

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `script.js` — интерактив (меню, счётчики, форма, анимации)
- `logo.svg.png` — логотип
- `app-icon.svg.png` — иконка приложения
- `photo_*.jpg` — скриншоты мобильного приложения
